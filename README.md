# Fossify Messages
<img alt="Logo" src="graphics/icon.webp" width="120" />

Private, open-source SMS/MMS messaging app with no ads or internet permission.

[<img src="https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png" height=80/>](https://play.google.com/store/apps/details?id=org.fossify.messages)
[<img src="https://fdroid.gitlab.io/artwork/badge/get-it-on-en.svg" height=80/>](https://f-droid.org/packages/org.fossify.messages/)

Features: SMS/MMS, message blocking, backup/restore, dark theme, search, group messaging.
